# MAYO Gaming Shop

אתר החנות של MAYO, חנות הגיימינג הזולה בארץ.

| קובץ | מה יש בו |
|---|---|
| `index.html` | דף החנות: מוצרים, עגלה והזמנה בוואטסאפ |
| `styles.css` | העיצוב של כל הדפים |
| `privacy.html` | מדיניות פרטיות |
| `accessibility.html` | הצהרת נגישות (ת"י 5568) |
| `404.html` | דף "לא נמצא" |
| `images/` | תמונות המוצרים (WebP, בגודל מלא ובגודל 280) |
| `fonts/` | הגופן Heebo, מאוחסן באתר עצמו |
| `og.png` | התמונה שמופיעה כשמשתפים קישור |

## לפני שהאתר עולה באמת

- מספר הוואטסאפ: `WHATSAPP_NUMBER` ב-`index.html`, וגם הקישורים `wa.me` ב-`privacy.html` וב-`accessibility.html`.
- פרטי רכז הנגישות ב-`accessibility.html` (שם ואימייל).
- המוצרים: הרשימה `PRODUCTS` ב-`index.html`.
- להסיר את השורה "אתר לדוגמה" (`demo-bar`) ב-`index.html`.
